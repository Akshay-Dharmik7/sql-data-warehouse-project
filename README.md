# 📊 SQL Data Warehouse Project

A modern **SQL Data Warehouse** project built using industry-standard data engineering and data modeling practices. This project demonstrates how to design, build, and analyze a data warehouse using the **Medallion Architecture (Bronze, Silver, Gold)**, enabling efficient reporting and business intelligence.

---

## 🚀 Project Overview

This project showcases an end-to-end data warehouse solution, covering the complete lifecycle from data ingestion to business analytics.

### Key Features

- 🏗️ **Data Architecture**
  - Designed using the **Medallion Architecture**
  - Bronze Layer – Raw data ingestion
  - Silver Layer – Data cleansing and transformation
  - Gold Layer – Business-ready analytical data

- 🔄 **ETL Pipeline**
  - Extract data from multiple source systems
  - Transform and clean the data
  - Load data into the warehouse

- 📐 **Data Modeling**
  - Star Schema design
  - Fact and Dimension tables
  - Optimized for analytical queries

- 📈 **Analytics & Reporting**
  - SQL-based business reports
  - KPI generation
  - Business insights for decision-making

## 🏛️ Data Architecture

This project follows the **Medallion Architecture**, which consists of three layers:

### 🥉 Bronze Layer
- Raw data ingestion
- Stores data exactly as received
- No transformations

### 🥈 Silver Layer
- Data cleansing
- Standardization
- Data quality improvements
- Business rule implementation

### 🥇 Gold Layer
- Business-ready datasets
- Fact and Dimension tables
- Optimized for reporting and analytics

---

## 📂 Data Sources

The project uses data from two different business systems:

- ERP System (CSV Files)
- CRM System (CSV Files)

These datasets are integrated into a unified analytical data model.

---

## ⚙️ Project Specifications

### Data Import
- Import data from ERP and CRM CSV files.

### Data Quality
- Clean missing values.
- Remove duplicates.
- Standardize data formats.
- Resolve data quality issues.

### Data Integration
- Merge ERP and CRM data into a single analytical model.

### Scope
- Focus on the latest available data.
- Historical data tracking (Slowly Changing Dimensions) is not included.

### Documentation
- Maintain clear documentation for developers, analysts, and business stakeholders.
